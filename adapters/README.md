# Adapters

Исследовательское ядро загружает сценарии напрямую из YAML. В локальном стенде E4 уже реализованы два адаптера: типизированный YAML-реестр и JSON доменных событий, см. [код](../src/datamesh_release_protocol/stand/adapters.py) и [инструкцию стенда](../stand/README.md).

Полноценные коннекторы ODCS/AsyncAPI и OpenMetadata API этим не реализованы. Автономное обследование и SQL/dbt-коннекторы относятся к [плану продукта](../docs/product-rebuild-2026-10-16.md), а не к готовому содержимому этого каталога.
