# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Coding agents working with a developer; a pilot participant observes the mechanism through a Russian interface.

## Product Purpose

Make the path from an API change to its affected consumer, exact source evidence, real consequence and repair understandable. This synthetic demonstration makes no claim about demand, saved labour or release authorization.

## Operating Context

Approved PR29 spec and implementation plan at 778b7668fd78e7c9dbaa8c0e6ce07b48ce9d82e4. Batch 2 owns this app; batch 1 owns the graph core and model qualification. Operator-controlled runtime is separate from the web app. Deployment is a later handoff, not an action in this PR.

## Capabilities and Constraints

Executable A/B/D/E HTTP scenario with independent exact-set checks. Static discovery uses a pinned external agent_graph CLI. Immutable history, bounded durable queue, explicit proposed/running versions. One sandbox across the installation. No web Docker socket, shell, cloud credentials or SSH. No live model calls here. A static finding, unapproved candidate, human correction, real check and external report retain separate meanings.

## Evidence on Hand

Synthetic 250-ID dataset; executable source versions; actual CLI outputs and operator receipts. Historical model experiments are not demo successes. Actual screenshots and acceptance results are recorded after execution.

## Accessibility & Inclusion

Russian task-first UI, keyboard-operable graph and evidence controls, readable laptop layout, 390px sequential panels, states distinguished by words as well as colour.

## Product Principles

- Show exact evidence before asking the reader to trust an edge.
- Keep a predicted risk separate from a real consequence.
- An unknown result remains unknown.
- Preserve history and show when it no longer applies.
