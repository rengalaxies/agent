# Квалификация открытой модели для автономного MVP

Новые программы экспериментов пачки 2Б. Серия 22.10 (`experiments/evidence_refs_v2`) закрыта и
сюда не входит: её ledger, ответы и 44 попытки не открываются и не учитываются.

Каждая программа лежит в `programs/<revision>/` и после первого живого запроса не меняется.
Изменение prompt, схемы, моделей, лимитов или порогов делается новой ревизией с новым `run_id`.

| Файл | Что фиксирует |
| --- | --- |
| `program.json` | run_id, модели и цены, параметры запросов, фазы, правила перехода, пороги evaluation |
| `models.json` | проверка документации Cloud.ru: ссылки, дата, возможности моделей, оговорки |
| `cases/<split>/*.json` | случаи: задача (недоверенный текст), репозитории с файлами, адреса сервисов, лимиты |
| `oracle/<split>.json` | эталон только для оценщика: ожидаемые утверждения, уверенность, impact, основание |
| `manifest.json` | хеши всего перечисленного, кода runner и протокола, объём и стоимость |

Случаи и эталон генерирует `tools/autonomous_mvp/generate_cases.py`; тест требует побайтного
совпадения с закоммиченными файлами. Эталон проверяет `tools/autonomous_mvp/oracle_check.py`:
он исполняет код фикстур с записывающими подменами `requests`/`httpx` и запускает собственные
тесты требований фикстур. Модель и статический extractor эталон не определяют.

Отчёт о подготовке, команды запуска и состояние: `docs/implementation/autonomous-mvp/batch-2b.md`.
