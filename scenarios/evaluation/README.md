# Отложенный каталог E3

Каталог содержит 40 зафиксированных evaluation-сценариев: 20 опасных и 20 допустимых изменений по семействам F1-F6. Он сформирован после внутренней заморозки протокола 0.3.0, V1-ind и метрик.

Входные YAML-файлы не содержат эталонных решений. Oracle хранится отдельно в `oracles/evaluation.yaml` и не передаётся валидаторам. Сценарии одного шаблона находятся только в evaluation; точные семантические переходы development-набора не повторяются.

Основной scored-запуск E3 на этом каталоге ещё не выполнялся. После просмотра результатов запрещено исправлять правила и использовать тот же набор для подтверждающего вывода без новой версии протокола и нового evaluation-набора.
