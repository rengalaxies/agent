# Отложенный каталог E3

Каталог из 40 итоговых сценариев здесь пока отсутствует намеренно. Он формируется только после внутренней заморозки версии V0/V1-ind/V1-oracle/V2 и не используется для исправления правил по результатам основной проверки.

Сценарии, созданные из одного шаблона или его мутаций, должны целиком находиться либо в development, либо в evaluation.
