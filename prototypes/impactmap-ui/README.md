# ImpactMap — A6.1 UX prototype

Локальный throwaway-прототип выбранного владельцем варианта2: [визуальная цель](../../docs/product/ui-admin-2026-11-16/visuals/workbench.png). HTML/CSS/JS, без новых runtime dependencies. Синтетические сценарии, MODEL не вызывается; реальная авторизация/данные/интеграции отсутствуют. Переключение роли имитирует только навигацию и не защищает публичные fixture-файлы.

```sh
python3 prototypes/impactmap-ui/serve.py
```

Открыть `http://127.0.0.1:18087/#/changes/pr5`. Сервер слушает только loopback, не публиковать в интернет. Ctrl-C останавливает его. Не помещать реальные данные/ключи в эту папку.

Основные пути: `#/changes/pr5`, `#/changes/pr4`, `#/changes/pr3`, `#/operations`, `#/connections`. Поиск, выбор поколения авторского примера, основание/просмотр кода, переход к ошибке, подключению и явной привязке работают локально. Дополнительные состояния доступны в раскрывающемся разделе списка: empty/closed/incompatible/unknown code.

Список ограничен примером из3 изменений; последние100 — согласованная граница будущего первого API. Переключение поколения — два подготовленных авторских случая, не реализованный архив сервиса. Команды повторов/публикации/подключения не выполняются.

Иконки — [Tabler Icons](https://github.com/tabler/tabler-icons), стандартные файлы с MIT license в `assets/icons/LICENSE`; URL и SHA каждого файла — `assets/icons/sources.json`. Системный sans-serif, без загрузки шрифтов и assets с внешних CDN во время работы. Концепт не содержит растровых иллюстраций; ImpactMap — текстовый wordmark.

План: [A6.1](../../docs/superpowers/plans/2026-11-16-impactmap-a6-1-prototype.md). Browser-verification и сравнение с reference записываются в `design-qa.md`; прототип не является готовой админкой и не закрывает A6.2–A6.5.
