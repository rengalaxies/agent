# Проверенная смета UI + private core и реальная возможность подключения
Дата 2026-10-13. Status: priced design / NOT PROVISIONED.
Проект Cloud.ru: `20853297-65b7-42a8-af40-25c8d2df4e11`.
**Размещённый в переписке секрет считать раскрытым. Немедленно отозвать и заменить. Никакие секреты сюда не копировать.**

## Проверка технической возможности
- Официально подтвержден Cloud.ru Evolution Terraform provider и примеры создания ВМ, private subnet, floating public IPv4, interface, VM disks.
- Подключения Cloud.ru в доступных app/connector tools нет. Исходящие HTTPS-запросы из текущей container runtime не проходят DNS resolution (проверялись cloud.ru и api.github.com). Значит **невозможно честно утверждать, что ВМ создана, авторизация API выполнена или грант/квоты просмотрены**.
- Доступный GitHub connector позволяет подготовить и сохранять Infrastructure-as-Code, но не запускать Terraform в Cloud.ru. Реальный apply требует исполнения в авторизованной среде (например, локальный Terraform на компьютере автора или настроенный runner с безопасными secrets); без проверки нельзя заявлять поддержку конкретного route API.
- Руководство Cloud.ru Terraform: https://cloud.ru/docs/tutorials-evolution/list/topics/vm__vm-terraform ; подробный шаблон: https://cloud.ru/docs/terraform-evolution/ug/topics/guides/vm_create_full

## Публичная таблица тарифов
Официальная таблица тарифов (версия 260619, с НДС 22%): https://cdn.cloud.ru/docs/legal/tariffs/evolution/current-version/evolution-compute.pdf

- Core VM 8vCPU/32GB: 15.9576 ₽/час.
- Alternative core 4vCPU/32GB: 12.0414 ₽/час.
- IPv4: 0.2074 ₽/час.

Для SSD **0.0156 ₽/(GiB·час) взято только из иллюстративного примера**, не подтверждено как действующая тарифная ставка: https://cloud.ru/docs/disks/ug/topics/pricing

## Сценарная калькуляция / 30 дней (720 часов)
Конфигурация: UI always-on 2/4 + 30GB SSD; core 8/32 на 160 рабочих часов + 200GB SSD на 720 часов; публичный IPv4 только UI на 720 часов; отдельный sNAT на 720 часов **если требуется**, он не заменяет правила private egress.
| Item | Formula | RUB |
|---|---|---:|
| UI compute | 2.9707 * 720 | 2,138.90 |
| Core compute | 15.9576 * 160 | 2,553.22 |
| UI SSD (примерная ставка!) | 30 * .0156 * 720 | 336.96 |
| Core SSD (примерная ставка!) | 200 * .0156 * 720 | 2,246.40 |
| Public IPv4 | .2074 * 720 | 149.33 |
| sNAT (optional) | .2074 * 720 | 149.33 |
| SUBTOTAL excluding NAT | | **7,424.81** |
| SUBTOTAL including NAT | | **7,574.14** |
| 25% capacity reserve including NAT | 7,574.14 * 1.25 | **9,467.68** |
Не включены: вызовы LLM, snapshot/backup/object storage, возможные иные сетевые услуги/условия договора. Пример ставок SSD требуется заменить актуальной договорной ставкой. Квоты и grant balance неизвестны.

Если core 8/32 включать 720 часов, увеличение против 160ч = 560*15.9576 = 8,936.26 ₽, total including NAT ~16,510.39 ₽ до моделей и backup. Это важнейший рычаг экономии. Для первой итерации с постоянным UI целевой месячный лимит 15,000 ₽ условно достижим при core 160ч, но не гарантирован.
Сценарная ресурсная альтернатива: core 4/32 вместо 8/32 экономит ~626.59 ₽ за 160ч, но медленнее и может не выдержать Kafka + agents. Не урезать память UI ниже 4GB без profiling.

## Нельзя игнорировать деградацию
Выключенный core означает, что UI публично доступен, но **интерактивные проверки недоступны**. UI должен показывать `DEMO BACKEND OFFLINE`, использовать предварительно сохранённые trace/storyboard, не выдавать запись за live result. Для live интервью core запускать заранее и проверять health.
При дефиците RAM заменить полнофункциональный Kafka окружения на режим с меньшим числом событий только для demo, сохраняя исследовательский Kafka в отдельном профиле. Нельзя смешивать эти результаты как равные. Отдельно устанавливать требования по E4 и E1.

## Gate перед provisioning
1. Автор отозвал секрет, новый выпущен и сохранён в секретном хранилище/локальном Terraform окружении.
2. В UI Cloud.ru сверены actual VM flavors, current SSD tariff, допустимость публичного IP, SNAT и месячные grant/quotas.
3. Выделен hard или soft cost control; стоимость VMs/IP/disks/LLM/backup + 25% reserve <= заданного лимита.
4. Пользователь подтвердил *именно полную цену* и создание платных ресурсов.
5. Terraform init/plan/apply в среде с outbound connectivity и доступом к проекту; state-файлы содержат чувствительные значения, хранить локально шифрованно либо в защищённом backend, в Git не коммитить.
