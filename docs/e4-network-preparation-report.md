# Подготовка пачки 2: сетевой E4-N

Дата: 2026-09-23. Добавлены HTTP-служба V2 для трех доменов, координатор с
HMAC-проверкой ответов и существующим SQLite-журналом, конфигурационный пример,
CLI, smoke test и инструкция по развертыванию на трех машинах. Служба домена
получает только собственные обязательства; каждый сервис запускается отдельно.

Локально на одном компьютере воспроизведены 5/5 проверок:
три сервиса ответили; три повторные доставки не изменили `ACCEPT`;
задержавшийся mobility и остановленный mobility дали `NEEDS_REVIEW`.
Также выполнена команда координатора из инструкции с локальным JSON-конфигом.
Сырые данные: `results/e4-network-loopback.json`. В JSON явно указано
`three_separate_environments: false`. Измеренный `elapsed_ms` включает запуск
запросов и ожидание ошибок и не является SLA трех сред.

Пакет подготовлен для проверки на трех машинах, однако развертывание и
измерение трех сред не проводились. Это предварительная техническая
верификация сетевого обмена, не доказательство H3 или H1. Для следующего
вывода необходимы четыре JSON-запуска и SHA общего коммита согласно
`docs/e4-network-three-environments.md`.
