# Изменения по мини аудиту защиты

Срез 27 ноября 2026 года. H1, результаты и технический вклад сведены в явную аргументацию. Дополнительно выполнен авторский технический прогон E6. Сессии с разработчиком и продактом подготовлены, фактические наблюдения ожидаются.

## Гипотеза и вывод

H1 для независимой серии — recall не ниже 90%, precision не ниже 85%, максимум один отрицательный случай с лишним сигналом из 14. При валидной серии нарушение любого порога означает, что H1 не поддержана. Невалидная серия даёт неопределённый исход. Рабочие пороги предложены автором и требуют согласования до независимого прогона.

Вмешательство — статическое сопоставление API и вызовов с версионированным основанием. Baseline LS1 выполняет буквальный поиск route через rg --fixed-strings в разрешённых consumer-файлах. Его кандидаты оцениваются по тем же ожидаемым потребителям и свидетельствам.

E3 — сохранённая авторская development-серия. E6 — дополнительная авторская диагностика с ожиданиями до запуска. Статус независимой H1 остаётся открытым.

## Новый технический результат E6

Использован публичный снимок E2 f50cdf255c5da36fcfc5882ffb1638c1348e190c, модельный слой выключен. Десять синтетических случаев составлены автором и инструментом на известных механизмах. Девять групп содержат связанные варианты. Внешних экспертов и независимых случаев ноль.

| Проверка | ImpactMap | LS1 |
|---|---|---|
| TP / FP / FN внутри профиля | 3 / 0 / 0 | 3 / 3 / 0 |
| Отрицательные случаи с лишним кандидатом | 0 из 4 | 3 из 4 |
| Внепрофильные случаи | Две обозначенные границы и FAILED/commit_unavailable | Подробные исходы в таблице по случаям |

Всего 20 первых назначенных попыток. Общий лимит 60 секунд на попытку. До outputs сохранены план, исходники и ожидания. После результатов продукт и оценщик не менялись. Все raw payload, нормализованные результаты, receipts и summary сохранены.

Для комиссии подготовлены три разбора
- AUD-0001 — удалён endpoint, есть прямой вызов.
- AUD-0004 — consumer явно передаёт прежний page_size, найденный LS1 текстовый кандидат лишний относительно авторского ожидания.
- AUD-0010 — provider недоступен, результат FAILED с commit_unavailable требует восстановления доступа.

## Личный вклад и нагрузка

Реестр десяти технических задач связывает требования и приёмку с кодом и доказательствами. Атрибуция отдельных программных изменений относится к исходной истории Git. Реальные трудозатраты за семестр предстоит подтвердить по учёту автора.

В дневнике и отчёте согласованы пять крупных направлений и пять групп подготовленных артефактов. Независимая серия и пользовательский эксперимент сохраняются отдельными незавершёнными задачами. Общий процент готовности не рассчитывается.

## Две пользовательские сессии

По сообщению автора есть разработчик и продакт. Для каждого подготовлены две задачи, исходники, фактическая карточка ImpactMap и форма ответа. Эталон хранится в отдельной инструкции модератора.

H-U-pilot проверяет, сможет ли участник без содержательной подсказки указать четыре корректных элемента — потребителя, основание, риск либо ограничение и следующий шаг. По каждому заданию фиксируются ответ, четыре оценки 0/1, критическая ошибка, активные минуты и помощь. Статус сессий NOT_RUN. Дизайн позволяет наблюдать понимание и ошибки. Сравнительное сокращение труда требует отдельного дизайна.

Сессия занимает ориентировочно 30–40 минут, её фактическая длительность ещё не измерена. После заданий отдельно обсуждается недавний реальный случай, обычный процесс, барьер пилота и следующий шаг. Рекрутинг и наличная готовность участников по сообщению автора не считаются проведёнными наблюдениями.

## Маршрут выступления

Целевой формат для репетиции — 4 минуты общей части и 5 минут личной, по путеводителю промежуточных презентаций. Применимость к конкретной комиссии 1 декабря ещё требует подтверждения.

Общая часть — слайды 1, 2, 4, 6, 8, 9, 11, 12, 13, 14. Личная часть — 1, 2, 4, 5, 7, 8, 9, 12. Остальные слайды сохранены скрытыми приложениями, в PDF доступны все страницы. Маршрут ещё нужно проверить речевым прогоном с таймером.

## Статус оценочных документов

Чек-лист и шаблон отчёта содержат различную детализацию и веса критериев. Поля официального шаблона сохранены. Прогноз баллов не вычислялся. Точный применяемый блок оценивания уточняется у организаторов.
