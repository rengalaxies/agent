# Реестр утверждений короткой презентации

24.10.2026. «Есть» означает реализацию/запуск с указанными условиями;
«цель» — согласованный продуктовый сценарий; «гипотеза» — непроверенную
полезность. Оговорка об автономном MVP видна на обложке и слайде 7.

| ID | Утверждение | Статус | Слайды / основание |
|---|---|---|---|
| C1 | Команде нужен ранний ответ о соседних потребителях | Гипотеза о спросе | 1–2, OFFER |
| C2 | Один вызов Reporting → GET /orders может потребовать проверки полноты | Иллюстрация; механизм воспроизведён на синтетике | 2, GRAPH и приёмка демо |
| C3 | Jira даёт предварительный вывод, PR уточняет его | Цель; интеграции пока нет | 3, DECISIONS A3 |
| C4 | Общий граф обновляет основания из кода и наблюдений, доступен агенту/человеку | Цель; сейчас статическая карта и история контекстов | 4, GRAPH |
| C5 | Факт, наблюдение и кандидат имеют разную силу | Принцип ядра; расширение на runtime — план | 4, аудит интеграции / GRAPH |
| C6 | Отсутствие трафика не доказывает отсутствия зависимости | Ограничение наблюдений | 4, GRAPH / Tempo docs |
| C7 | Альтернативы умеют инструменты, навигацию, контракты или граф вызовов | Первичные источники, не сравнительный эксперимент | 5, SOURCES |
| C8 | Актуальный общий контекст может дать инсайт раньше | Гипотеза преимущества | 5, проверяется по PROTOCOL |
| C9 | Коробка и обычная работа без постоянного оператора | Цель; не готовая эксплуатация | 6, INSTALLATION / CONSTITUTION |
| C10 | Есть узкое ядро, основания, история, синтетическое демо | Подтверждено кодом и отчётами; клиентский эффект не измерен | 7, EVIDENCE |
| C11 | Нужны автоматические Jira/PR, runtime-граф и квалифицированная модель | План инженерных пачек | 7, BACKLOG |
| C12 | Эффект проверяется по времени, качеству, ручному труду и стоимости | Предложенный протокол, численных результатов нет | 8, PROTOCOL / ECONOMICS |

Нет утверждений о гарантированной экономии, полноте, уникальности графа,
неспособности других агентов давать ссылки, готовности Qwen или автономной
работе нынешней ВМ. Нет обязательных оператора, разметчика и инженера на задачу.
