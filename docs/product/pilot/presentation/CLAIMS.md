# Реестр ключевых утверждений презентации

Редакция 24.10.2026. Срез: `main` = `8f010cf`, предложение пилота = ветка
`docs/pilot-proposal` (`0fab62a`, PR #47, открыт). Каждый текст на слайдах
опирается на строку этого реестра. Утверждения без строки в реестре в
презентацию не попадают.

## Статусы

| Статус | Что значит | Как звучит на слайде |
|---|---|---|
| **Подтверждено** | Результат запуска, теста или замера с указанным корпусом и версией, либо прямое чтение кода | Утвердительно, с указанием условий (синтетика, корпус, ОС) |
| **Гипотеза** | Утверждение о клиентах, рынке, пользе, затратах или поведении, которое никто не проверял, включая оценки до замера | Как вопрос к собеседнику, "предполагаем", "оценка до замера" |
| **План** | Предложенное условие пилота или работа, которую ещё предстоит сделать | "в пилоте", "до старта сделаем", "предлагаем" |

## Рабочая гипотеза продукта

В репозитории есть три несведённые формы продукта: граф для coding agent
через CLI или MCP (`PRODUCT.md`, useful-graph §1.1), интерфейс для
разработчика (демо и UX-аудит), отчёт автору изменения в PR (предложение
пилота, решения D2, D6). Презентация берёт третью как **рабочую гипотезу**
и так её и называет на слайде 4. Основание выбора: последствия ошибки несёт
человек, понятность UI на людях не проверена (EVIDENCE K1, I3). Сами решения
D1-D17 имеют статус "Предложено" и ждут владельца на пересмотре 27.10.2026,
поэтому в основном рассказе пилот подаётся как предложение, а не как
утверждённый продукт.

## Что в презентацию не попадает

| Утверждение | Почему |
|---|---|
| Любая экономия времени или денег клиента | Не измерялась ни разу (ECONOMICS §5) |
| Цена 100-150 тыс. руб. | Отозвана (DECISIONS D12) |
| Покупатель это руководитель платформы (H5) | Не проверено; в заметках как вопрос |
| Основной пользователь графа это coding agent (H2) | Решение команды, не наблюдение; в пилоте пользователь отчёта человек |
| Встроенный агент сопровождения графа | Противоречит O9, исключён D5 |
| RabbitMQ, другие языки и клиенты HTTP | Кода нет, работа остановлена (README-pilot "Что перестаём делать") |
| Срок поиска клиента до 13.11.2026 и критерий остановки трека | Внутреннее решение команды, не часть предложения клиенту |
