# Заметки к восьми слайдам

Редакция 29.10.2026: факты поставленного сервиса и условия закрытого пилота.

## 1. Кого затронет следующее изменение?

Сервис для команд, которые меняют внутренние HTTP API. Предлагаем закрытый технический пилот на поддерживаемом профиле HTTP/Python. Модель выключена. Спрос, экономия и польза для команды не измерены.

Источники:
- docs/product/pilot/OFFER.md

## 2. Изменение API затрагивает соседнюю команду

Иллюстрация: задача предлагает ограничить выдачу заказов. Граф связывает потребителя с операцией и основанием. Статическая связь и наблюдение вызова помогают выбрать проверку, но не доказывают будущую поломку. Пример не является клиентским кейсом.

Источники:
- docs/product/pilot/GRAPH.md
- docs/agent-graph-demo/deployments/2026-10-22/README.md

## 3. Jira предупреждает раньше. PR уточняет.

Два входа в один анализ. Задача Jira даёт предварительную область влияния до кода. PR уточняет её по diff двух коммитов. Оба пути реализованы и проверены локально и в CI; на настоящих GitHub и Jira ещё не запускались. Один комментарий обновляется при каждом изменении, оператор на задачу не нужен.

Источники:
- docs/product/pilot/OFFER.md
- docs/implementation/autonomous-mvp/READINESS.md

## 4. Граф связывает код с работой сервисов

Граф хранит связи с основаниями: источник, версия или окно наблюдения, свежесть. Код даёт объявленные вызовы в профиле HTTP/Python. Структурированные журналы доступа дают наблюдения; трассы пока не подключаются. Статическая находка, наблюдение и гипотеза показываются раздельно.

Источники:
- docs/product/pilot/GRAPH.md

## 5. Альтернативы и наша гипотеза преимущества

Сравнение задач по официальным источникам от 24.10.2026; общий эксперимент качества не проводился. Qwen-Agent поддерживает инструменты и MCP. Sourcegraph умеет точную навигацию SCIP. oasdiff сравнивает OpenAPI, Pact проверяет контракты. Tempo строит граф из трасс. Не утверждаем, что у альтернатив нет проверяемых оснований. Гипотеза сервиса — общий актуальный контекст кода и runtime для раннего Jira/PR-инсайта.

Источники:
- https://github.com/QwenLM/Qwen-Agent
- https://sourcegraph.com/docs/code-navigation/precise-code-navigation
- https://www.oasdiff.com/docs/getting-started
- https://docs.pact.io/
- https://grafana.com/docs/tempo/latest/metrics-from-traces/service_graphs/

## 6. Подключение один раз — работа по событиям

Релиз ставится на Linux-ВМ через systemd. Установка, обновление и откат проверены на CI-раннере, на целевой ВМ Cloud.ru ещё нет. Владелец один раз подключает GitHub App, при желании Jira, и репозитории. Модель выключена, анализ детерминированный. Секреты хранятся вне Git.

Источники:
- infra/agent_service/README.md
- docs/product/pilot/CONNECT.md

## 7. Что проверено и что ещё нет

Проверено локально и в CI: webhook Jira и PR, один обновляемый комментарий, основания вида репозиторий@коммит:строка, установка и откат релиза, локальный показ изменение, исправление, нейтральный контроль. Не проверено: настоящие App и Jira, установка на целевой ВМ, незнакомый проект и польза. Модель не прошла транспортный допуск и выключена.

Источники:
- docs/implementation/autonomous-mvp/READINESS.md
- docs/implementation/autonomous-mvp/pilot-2026-10-29/README.md

## 8. Закрытый пилот: один сквозной сценарий

Пилот на одном HTTP/Python API и его потребителях, 2–5 репозиториях GitHub и проекте Jira, если он есть. Права: чтение кода и PR, запись только своих комментариев. До прогона согласуем критерии и правила остановки. Человеческие минуты считаем отдельно от машинного времени. Цена, срок и объём пока предложение с допущениями.
