# Заметки к восьми слайдам

24.10.2026. Основной рассказ о целевом автономном сервисе; реализация и план разделены.

## 1. Кого затронет следующее изменение?

Целевой автономный B2B-сервис. Помогает команде заранее увидеть возможное влияние изменения на соседние команды. Полный автономный сценарий ещё не реализован; экономия и спрос не измерены.

Источники:
- docs/product/pilot/OFFER.md

## 2. Изменение API затрагивает соседнюю команду

Иллюстрация: задача предлагает ограничить выдачу заказов. Граф связывает потребителя с операцией и основанием. Статическая связь и наблюдение вызова помогают выбрать проверку, но не доказывают будущую поломку. Пример не является клиентским кейсом.

Источники:
- docs/product/pilot/GRAPH.md
- docs/agent-graph-demo/deployments/2026-10-22/README.md

## 3. Jira предупреждает раньше. PR уточняет.

Два входа в общий анализ. Jira работает с намерением и даёт предварительную область влияния. PR работает с diff по двум SHA и уточняет конкретные места. Оба результата — план первого автономного выпуска. Один комментарий обновляется; не нужен оператор на каждую задачу.

Источники:
- docs/product/pilot/OFFER.md
- docs/product/pilot/DECISIONS.md

## 4. Граф связывает код с работой сервисов

Граф — обновляемая память с основаниями: кто вызывает кого, по какому источнику и когда это актуально. Код даёт объявленные вызовы; трассы или подходящие логи — наблюдения. Агент использует карту при анализе; человек может открыть путь и источник. Статическая находка, runtime-наблюдение и модельная гипотеза раздельны. Runtime-коннектор и устойчивый граф пока план.

Источники:
- docs/product/pilot/GRAPH.md
- https://grafana.com/docs/tempo/latest/metrics-from-traces/service_graphs/

## 5. Альтернативы и наша гипотеза преимущества

Сравнение задач по официальным источникам от 24.10.2026; общий эксперимент качества не проводился. Qwen-Agent поддерживает инструменты и MCP. Sourcegraph умеет точную навигацию SCIP. oasdiff сравнивает OpenAPI, Pact проверяет контракты. Tempo строит граф из трасс. Не утверждаем, что у альтернатив нет проверяемых оснований. Гипотеза сервиса — общий актуальный контекст кода и runtime для раннего Jira/PR-инсайта.

Источники:
- https://github.com/QwenLM/Qwen-Agent
- https://sourcegraph.com/docs/code-navigation/precise-code-navigation
- https://www.oasdiff.com/docs/getting-started
- https://docs.pact.io/
- https://grafana.com/docs/tempo/latest/metrics-from-traces/service_graphs/

## 6. Подключение один раз — работа по событиям

Целевая установка: закреплённый релиз на Linux-ВМ; Cloud.ru — адаптер создания ВМ с тем же installer. Владелец один раз задаёт доступы и рамки ресурсов. Модель может использовать внутренний либо отдельно согласованный внешний endpoint. Конституция исполняется инструментами, схемами, правами и лимитами. Повторная установка, восстановление и возврат обязательны, но пока не проверены для автономного сервиса.

Источники:
- docs/product/pilot/INSTALLATION.md
- docs/product/pilot/CONSTITUTION.md
- https://cloud.ru/docs/terraform-evolution/ug/topics/quickstart

## 7. Что работает сейчас и что входит в MVP

Сейчас узкое статическое ядро requests/FastAPI/OpenAPI JSON, digest и строки, история контекстов, синтетическое демо. PR45/46 слиты. Пока нет автономных Jira/PR, runtime-коннектора, устойчивого графа и проверенной коробки нового сервиса. Qwen 0/3 в серии остановился на invalid_model_action до семантики, поэтому сначала диагностика/согласование протокола, затем квалификация. Не обещать готовность модели или срок из старого ручного пилота.

Источники:
- docs/product/pilot/EVIDENCE.md
- docs/product/pilot/BACKLOG.md
- experiments/evidence_refs_v2/runs/2026-10-22-batch1/README.md

## 8. Первое подключение: один сквозной сценарий

После инженерной готовности выбрать один API и связанные потребители, доступный runtime-источник и проекты Jira/Git. До отложенной серии фиксируются критерии и независимо известные последствия. Нет постоянного инженера и разметчика; человеческие минуты поддержки измеряются отдельно. Цена, срок и экономия не установлены.

- docs/product/pilot/PROTOCOL.md
