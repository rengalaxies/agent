# Презентация пилота для встречи с клиентом

Редакция 24.10.2026. Встреча с техлидом команды, которая может стать
участником пилота, и руководителем, который выделяет время команды. Цель
встречи: согласовать предметный пилот, его владельца, исходные материалы и
следующую встречу.

Основа: предложение пилота из [`docs/product/pilot/`](../README.md). Оно ещё
не утверждено (PR #47 открыт, решения в статусе "Предложено"), поэтому
презентация подаёт пилот как предложение, а форму продукта "отчёт автору
изменения в PR" как рабочую гипотезу.

## Структура рассказа

1. Обложка.
2. Ситуация и цена неопределённости (гипотеза, проверяется вопросами).
3. Почему текущих способов не всегда достаточно.
4. Работа сервиса и форма результата (рабочая гипотеза).
5-7. Пример 250 → 100 → 250 на синтетическом стенде и экраны работающего приложения.
8. Что подтверждено.
9. ИИ-модель: фактический результат эксперимента и почему она выключена.
10. Где заканчиваются возможности.
11. Отличие от альтернатив и причина попробовать.
12. Что есть сейчас, что проверяем, что план.
13-15. Содержание пилота, обязанности сторон, критерии результата.
16. Предложение следующего шага.

Приложение П1-П11: методика, показатели, проба покрытия, стенд, модельная
серия, замеры, работа до старта, экономика, реестр утверждений, источники.

## Экраны приложения

Все экраны вырезаны из скриншотов целевой приёмки на ВМ 22.10.2026
(`docs/agent-graph-demo/deployments/2026-10-22/`) без ретуши. Строка
интерфейса "Независимая проверка сравнивает все 250 ID" из кадров убрана
обрезкой: аудит интеграции (F2) признал её неверной, на ВМ стоит сборка до
исправления. Кадра версии D нет, её результат взят из отчёта приёмки.

## Сборка

Нужны Node.js с `pptxgenjs@3.12.0`, Python с Pillow и, для рендера,
Windows с PowerPoint и `pywin32`. Из корня репозитория:

```bash
python docs/product/pilot/presentation/src/crop_screens.py
NODE_PATH=<каталог с node_modules> node docs/product/pilot/presentation/src/build.js
python docs/product/pilot/presentation/src/render.py
```

`build.js` пишет PPTX и `SPEAKER-NOTES.md`, `render.py` пишет PDF и PNG
слайдов в `src/renders/` (не коммитится). Тексты заметок правятся в
`src/notes.js`, тексты слайдов в `src/build.js`. Новое утверждение сначала
добавляется в `CLAIMS.md`.
