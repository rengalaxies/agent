# Короткая презентация автономного сервиса

Редакция 24.10.2026: восемь слайдов. Предназначена для обсуждения B2B-сервиса,
который разворачивается из коробки, обновляет граф связей и автоматически
выдаёт предварительный инсайт в Jira и уточнённый по PR. Это целевой MVP,
не утверждение, что новые интеграции уже реализованы.

## Сборка

`src/build.mjs` использует JavaScript и `@oai/artifact-tool` из настроенного
окружения; пакет и шрифты не скачиваются этим скриптом. Нужны Node.js,
Arial с кириллицей и LibreOffice (`soffice`). PDF конвертируется из того же
проверенного PPTX. `src/slides.json` сохраняет порядок, заметки и источники.

Для среды Codex зависимости определяет `load_workspace_dependencies`.
Задать `DECK_OUTPUT` и `DECK_PREVIEW` как новые каталоги. Для полной проверки
также задать `PRESENTATIONS_SKILL_DIR`, `RUNTIME_PYTHON`,
`RUNTIME_NODE_MODULES`, при необходимости `SOFFICE_BIN`.

```sh
node src/build.mjs
```

По умолчанию результат пишется рядом с этим README; финализатор не
перезаписывает существующий итоговый файл, поэтому для новой ревизии
рекомендуется новый `DECK_OUTPUT`. Полная проверка требует поставляемого
средой набора валидаторов, без него скрипт только экспортирует файлы.
Прежние `build.js` и нарезка скриншотов доступны в истории Git; для новой версии не используются.
