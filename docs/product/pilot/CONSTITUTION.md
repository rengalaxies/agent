# Конституция и инструменты агента

Это требования к реализации, не готовая конфигурация запуска. Конституция —
закреплённые правила. Промпт объясняет их модели, доверенный код ограничивает действия.

## До запуска

Источники/проекты/репозитории, окружения и идентичности; endpoint модели;
инструменты и права; отдельная публикация; лимиты времени/шагов/ресурсов/
денег; актуальность; поведение при конфликте и сбое. Секреты передаются
по ссылке из хранилища, не добываются моделью из документов.

## Обязанности

Синхронизация источников → факты и кандидаты → запрос графа по задаче/PR →
краткое объяснение с основаниями. Отдельная модель/процесс на каждую роль
не обязательны. Модель не выбирает произвольные shell-команды, не расширяет
доступ и не утверждает совместимость выпуска.

## Вне модели

Строгая схема action; allowlist инструментов/параметров; права; receipts
чтения и происхождение цитаты; версия; лимиты; публикация; дедупликация.
При сбое — ограниченный повтор, затем частичный результат или отказ.
Никакой бесконечной очереди ручного подтверждения.

Квалифицируется модель + шаблон + инструменты + конституция.
[Qwen-Agent](https://github.com/QwenLM/Qwen-Agent) поддерживает инструменты
и собственный endpoint, но не доказывает качество нашего сценария. Сначала
диагностика action-протокола, затем новая серия. Прежние 0/3 не доказывают
неспособности Qwen понимать зависимости.
