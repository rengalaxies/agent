# E6 Дополнительная авторская диагностика

27 ноября 2026 года. Источник — точный публичный снимок E2 f50cdf255c5da36fcfc5882ffb1638c1348e190c. Core и оценщик не менялись. Подготовлены 10 синтетических авторских случаев в 9 группах, одна группа содержит два связанных варианта. Семантические механизмы частично повторяют прежний development-набор. Автор и инструмент формировали входы и ожидания. Независимых экспертов 0, независимых случаев 0.

До попыток записаны plan-before-run.json, Git-входы, ожидания и контракты. Порядок 20 назначенных первых попыток сохранён в campaign-manifest.json. Общий cap — 60 секунд на попытку. Использованы существующие runner, normalizer и scorer tools.impactmap_eval. Полный результат находится в attempts/summary.json, исходные payload и receipts — в attempts/attempts. После результатов core не настраивался.

Внутри профиля 3 положительных и 4 отрицательных случая. У ImpactMap TP/FP/FN 3/0/0, ложные сигналы на отрицательных 0/4. У LS1 — 3/3/0, ложные сигналы 3/4. Вне профиля 3 случая. ImpactMap обозначил границу для httpx и динамического URL, недоступный provider дал FAILED с commit_unavailable. Ошибка доступа учитывается отдельным исходом. Эти числа описывают известный контролируемый набор.

LS1 использует rg --fixed-strings с route из operation_hints и возвращает буквальные совпадения в consumer-файлах как кандидатов. Сам LS1 не утверждает факт поломки. Scorer оценивает такие кандидаты по заранее созданному авторскому ожиданию. Поэтому FP здесь означает лишнего кандидата относительно этой разметки.

## Три разбора комиссии

- AUD-0001. Endpoint удалён, consumer вызывает его напрямую. Оба метода нашли потребителя, у ImpactMap есть адресное основание.
- AUD-0004. Значение по умолчанию уменьшено, consumer явно передаёт прежний page_size=60. ImpactMap воздержался, LS1 сохранил буквального кандидата. Это показывает механизм фильтрации в поддержанном профиле.
- AUD-0010. Исходный provider недоступен. ImpactMap вернул FAILED/commit_unavailable. Такой результат требует восстановления доступа, по нему нельзя разрешать выпуск или заключать об отсутствии влияния.

## Воспроизведение

Нужно получить публичный снимок E2, создать Python 3.12 окружение с extras .[api,test-api], установить jsonschema==4.26.0 и иметь git и rg в PATH. Из корня E2 запускаются prepare.py и python -m tools.impactmap_eval.calibrate --corpus <corpus> --output <new-output>. В prepare.py нужно выбрать новый доступный путь output перед созданием входов. Выходные каталоги создаются заново. Артефакты содержат локальные materialization paths, временные метки и Git metadata, поэтому равенство байтов разных запусков не обещается. Сравниваются семантические результаты и сохранённые идентификаторы каждого запуска.

Серия дополняет E3. План независимой H1 и пользовательская проверка остаются открытыми.
