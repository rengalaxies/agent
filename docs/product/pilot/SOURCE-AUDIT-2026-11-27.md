## Локальные тесты

Для извлечённого дерева E2 создано отдельное Python-окружение с объявленными extras `.[api,test-api]`. Команда из корня извлечённых исходников:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[api,test-api]'
PYTHONPATH=.:src:tests:tools .venv/bin/python -m unittest tests.service.test_bitbucket_allowlist tests.service.test_ui_areas tests.service.test_ui_auth tests.service.test_ui_links -q
```

## Как завершить публикацию

1. Восстановить доступ к исходной Git-базе; повторно проверить коммит и дерево E2, отдельно зафиксировать полный SHA и дерево E1.
2. Дослать оставшиеся объекты и построить дерево снимка. Для E2 итоговый SHA дерева должен совпасть с `43040f3654d12703815c96a6383ceaaf5eb5bb1d`.
3. Создать отдельную evidence-ветку. Если публикуется новый коммит с тем же деревом, указать оба SHA: исходный коммит и новый публичный. Одинаковое дерево не означает сохранения идентификатора или всей истории коммита.
4. Проверить checkout с GitHub, повторить выбранные тесты с Node в PATH и описать способ запуска без секретов.
5. Обновить [карту доказательств](EVIDENCE.md) и [реестр](TRACKING.md) только после подтверждения доступности полного снимка.
