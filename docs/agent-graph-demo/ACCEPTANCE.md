# Приёмка HTTP graph demo

Результаты обновляются после выполнения финальных проверок. Это исполняемое синтетическое демо, не модельный эксперимент и не приёмка целевой ВМ.

Первый рабочий локальный прогон использовал принятый core `a9385c565d5471698da62987b226dcff4cbdea86`: Chromium + настоящий backend/CLI, Docker Orders/Status/consumers, независимый oracle. A PASS (250/250); B ожидаемый FAIL (Reporting100, Billing250, пропуски101…250); D PASS (Reporting250); E PASS (Export250 и новое найденное ребро). Health связан с Status. История B открыта после E; тестовый HTML-фрагмент отрисован как текст. Пять последовательных сессий, после stop — ноль собственных sandbox. Ни одного модельного вызова.

После независимого UI finish-review исправляются stale SVG, гонка ответов evidence и мобильный переход к основанию. Финальный прогон/скриншоты и SHA будут записаны отдельным отчётным коммитом; старые промежуточные WORKTREE-результаты не объявляются проверкой финального SHA.

Оставшиеся интеграционные проверки: поставка immutable image + отдельного core pin, права root:10001 runtime и readonly mount на целевой ВМ, OS/Docker restart/reconciliation, peak RAM/CPU/cold-warm/OOM/disk/log growth на Ubuntu24.04/2CPU/4GiB, утверждённые DNS/TLS и внешняя operator/viewer проверка. Модельная квалификация принадлежит пачке1 и не включена в приёмку приложения. ВМ, secrets/vars и модельная серия не изменялись.
