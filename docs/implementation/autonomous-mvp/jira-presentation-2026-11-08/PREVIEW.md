# Предпросмотр русского Jira-комментария

Локальное отображение сохранённых реальных результатов; в Jira не публиковалось.
Полный результат остаётся в jobs.result и provider-neutral outbox body.
В Jira сохраняется одна служебная строка marker/digest для идемпотентности;
она не включена в этот предпросмотр пользовательского текста.


## До исправления

### Возможное влияние на другие сервисы

Найдены потребители, которые могут зависеть от изменяемой операции.

**Что может затронуть**

- reporting: ответственный не определён.

**Почему и через какой путь**

- В изменении удалена операция orders GET /orders/summary.
- Потребитель reporting: вызов в bb.reporting:client.py:14.
- Связь: reporting → orders GET /orders/summary.
- Основание в коде: bb.reporting:client.py:14.
- Основание в коде: bb.orders:api.py:14.

**Что проверить**

- Сохраните прежний маршрут или обновите вызов в reporting; затем проверьте совместимость.
- reporting: проверьте изменённую операцию на независимых ожиданиях потребителя.

**Ограничения**

- Не все вызовы и их поведение удалось сопоставить; часть влияния может быть пропущена.
- Ожидания потребителя не подтверждены; документационный контекст сам по себе их не доказывает.
- Интеграционные тесты в рамках этого анализа не запускались.

**Документация**

- Пилот Orders–Reporting — требования для KAN-8 — версия 4: https://rengalaxies.atlassian.net/wiki/pages/viewpage.action?pageId=360725
- Соответствие кода требованиям отдельно не проверялось.
