### Независимое ревью #75 и #76

Отдельный агент читал только diff, без выводов исполнителя. Исправлено с RED → GREEN:

- **Critical, #75.** После опубликованного риска FAILED, несовместимый или неясный
  результат давал «не обнаружено». Это ложное утверждение, ведь анализа не было. Теперь
  переход строится только для совместимых USEFUL, PARTIAL и `no_supported_delta`.
- **#75.** Пересчёт той же версии после смены профиля выглядел бы как исправление. Теперь
  раздел строится только при новой версии ресурса.
- **#75.** Сохранённые результаты старых релизов с другой формой роняли бы воркер.
  Теперь форма проверяется.
- **#76.** Reopen отзывал ожидающую stale-заметку, если новая версия ещё стояла в
  очереди. Такие ресурсы теперь пропускаются. Ресурсы провайдера, убранного из
  конфигурации, тоже пропускаются.

Известные ограничения, не исправлены:

- Пересчёт ставит все открытые ресурсы в очередь разом. Свежий webhook ждёт за ними,
  хвостовые задачи могут упасть по `deadline_exceeded`, тогда их поднимает `revive`.
- `published_result` может взять результат, показанный как «несовместим».
- Если источник графа недоступен постоянно, основа не записывается и пересчёта нет.
