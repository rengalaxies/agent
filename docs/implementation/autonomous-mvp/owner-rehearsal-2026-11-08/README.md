# Самостоятельный прогон владельца — 08.11.2026

Владелец выбрал «пока пройду сам». Пакет основан на существующем
[PARTICIPANT-SESSION](../../../product/pilot/PARTICIPANT-SESSION.md), адаптирован к
реальному Jira–Bitbucket–Confluence пилоту. Оригинальный протокол не меняется.

1. Сначала выполнить [TASKS](TASKS.md), не открывая лист ответов.
2. Записать ответы в копию responses.template.csv; затем разобрать по REVIEWER.md.
3. Пройти [сценарий показа](RUNBOOK.md) с секундомером и записать реальные замечания.

Человеческая сессия NOT_RUN; ответы/время/оценки пока не заполнены. Самостоятельный
прогон автора не закрывает независимый M4/M5, не измеряет FP/FN/экономию и не
является критерием коммерческой приёмки. Содержимое CASE-A/B — реальные сохранённые
результаты, а не ожидаемые ответы, с явно указанными временем и состоянием.

Read-only preflight: действующий systemd worker, status/graph200, notices0;
один FAILED intent остаётся ожидаемым отказом PR3 без Jira-ключа. Код/конфигурация
ВМ и внешние задачи в этой пачке не изменялись. Ни новой LIVE-серии, ни видео нет.
