## Что изменено

- Явный `page_size` проверяется отдельно от способа обхода страниц. Цикл с явно заданным размером больше не теряет этот факт. Освобождение касается только изменения одного default; полнота пагинации и общая совместимость не объявляются доказанными.
- Default-only требует доказанной query-привязки со стороны провайдера, неизменных остальных проверяемых оснований и явного непустого размера у конкретного вызова. FastAPI поддерживает здесь консервативную грамматику простых скалярных аннотаций; Annotated/Body/Query alias/контейнеры/неизвестные привязки не дают исключение. OpenAPI сравнение учитывает контекст пути, компоненты и общие настройки документа, без исполнения/разрешения произвольных ссылок.
- Два вызова на одной строке имеют разные ID по позиции. Неявный вызов не замещается соседним явным. При разных callsites одного потребителя остаётся предупреждение для вызова, использующего default.
- Изменение другого handler того же provider может затронуть вызывающий его handler как helper: исключение консервативно запрещено. Семантика helper не исполняется и граф вызовов Python не выдумывается. Это может сохранить лишнюю проверку для фактически независимого соседнего handler/компонента/модульной константы.
- Неотслеживаемые Python-изменения поставщика явно обозначаются `unclassified_change`/`helper_semantics_unknown`; потребитель не назначается без оснований. При выбранном operation_id посторонний provider repository не влияет на эту границу. Смешанный PR не получает ложную сводку Default-only.
- None, пустые/динамические значения, неизвестные kwargs, удаление операции, смешанные body/contract/import/helper изменения не освобождаются вслепую. Связи графа и delta сохраняются даже при отсутствии нового адресного предупреждения. Воздержание не называет существующего потребителя отсутствующим и не подтверждает совместимость.
- Профиль7 инвалидирует прежние контексты/knowledge. Output schema2.2 сохранена: новые утверждения используют существующие reason/unknown-коды. Для установки и модельной квалификации нужен новый конкретный release; производительность05 на profile6 автоматически на profile7 не переносится.
