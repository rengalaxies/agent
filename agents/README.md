# Agents

Исполняющий LLM-агентный слой в main пока отсутствует. В исследовательском протоколе агент готовит предложения, evidence и объяснения; окончательный `ReleaseDecision` остается детерминированным.

Целевой продукт расширяет функции до обследования, сборки кандидатов правил и выполнения межсистемного перехода через поддержанные API/events/handler/SQL. Планировщик связывает адаптации и приемку разных потребителей; состояние и вывод старого пути проверяются отдельно. Роли, ограничения и статусы описаны в [едином продуктовом документе](../docs/product-rebuild-2026-10-16.md). Агент не принимает свои кандидаты правил как нормативные, не расширяет права и не отменяет детерминированный запрет. Эти функции пока являются планом.
