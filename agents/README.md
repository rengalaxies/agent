# Agents

Исполняющий LLM-агентный слой в main пока отсутствует. В исследовательском протоколе агент готовит предложения, evidence и объяснения; окончательный `ReleaseDecision` остается детерминированным.

Целевой продукт расширяет функции до обследования, сборки кандидатов правил, планирования, адаптации, проверки и сопровождения. Роли, ограничения и статусы описаны в [едином продуктовом документе](../docs/product-rebuild-2026-10-16.md). Агент не принимает свои кандидаты правил как нормативные, не расширяет права и не отменяет детерминированный запрет. Эти функции пока являются планом.
